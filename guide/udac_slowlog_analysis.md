# 慢请求分析

数据库自治中心内置 Redis 慢请求分析功能，支持采集、持久化并可视化展示实例的慢请求命令，精准呈现命令内容、执行耗时、客户端来源等核心数据。该功能助力用户高效定位性能瓶颈、优化命令使用，提升实例可观测性与运维效率。


## 功能说明
- 慢请求数据每分钟自动采集一次，数据持久化保存，**实例重启不影响历史数据**。
- 支持查看历史数据，历史数据查询时间范围为30天内，且单次查询跨度不超过15天。
- 历史数据支持按耗时降序排列，单次最多展示 Top 1000 条记录，支持导出 CSV。
- 分布式实例支持按分片筛选，查看各分片的慢请求分布情况。
- 慢请求阈值由实例配置**slowlog-log-slower-than**决定。


## 具体操作

在实例管理列表中，点击目标实例操作列的"..."，选择"慢请求分析"进入操作页面。
![image](/images/slowlog_analysis_2.png)

进入页面后，顶部展示**慢请求趋势**柱状图，按时间聚合展示慢请求数量变化，支持分钟级或小时级粒度切换。点击或拖选图表中的时间段，可联动下方列表进行过滤。
![image](/images/slowlog_analysis_0.png)

![image](/images/slowlog_analysis_1.png)

页面下方为**慢请求明细列表**，展示以下字段：

| 字段 | 说明 |
|------|------|
| 执行时间 | 慢请求发生的时间戳 |
| 命令 | 完整慢请求命令（敏感参数已脱敏） |
| 执行耗时（ms） | 命令执行时长，单位毫秒 |
| 资源 ID | 对应的分片或代理节点标识 |
| 连接数据服务的主机地址 | 发起请求的客户端 IP |

对于分布式实例，可通过右上角的"集群"下拉菜单按分片进行筛选，查看指定分片的慢请求数据。


## 常见问题
### 为什么慢请求分析页面没有数据？
请检查实例的慢请求阈值配置，如阈值已正常配置，请确认所查询的时间段内确实存在执行耗时超过阈值的命令。
### 历史数据查询范围有什么限制？
历史数据支持查询30天内的记录，且单次查询的时间跨度不能超过15天。
### 分布式实例如何查看各分片的慢请求？
进入慢请求分析页面后，通过右上角的"集群"下拉菜单选择对应分片，即可查看该分片的慢请求数据。
### 实例重启后历史慢请求数据会丢失吗？
不会。慢请求数据已持久化存储，实例重启或主备切换不影响已采集的历史数据。
