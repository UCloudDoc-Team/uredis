# 会话管理

数据库自治中心 UDAC 提供 Redis 会话管理功能，可查看实例会话信息，并按 Redis 形态对会话或连接进行管理。本文配图为重新制作的功能示意图，所有实例、会话及连接数据均为虚构内容。

## 功能入口

进入数据库自治中心 UDAC 的**实例管理**页面，选择 **Redis**，在目标 Redis 实例的操作菜单中点击**会话管理**。

![Redis 实例操作菜单中的会话管理入口示意图](https://cdnv2-cache.udelivrs.com/2026/10/4003b92b0e71dc8419e538e18b0b1474_1792636340414.png)

进入会话管理页面后，可查看实例会话列表。页面支持手动刷新，也可通过自动刷新开关更新会话数据。

![Redis 实例会话列表示意图，数据为虚构内容](https://cdnv2-cache.udelivrs.com/2026/10/cad012dfdc6408698347bf28a0912522_1792636363338.png)

## 主备版 Redis

主备版 Redis 支持终止指定会话。选择目标会话后，可使用批量终止操作；终止前会展示待关闭的客户端会话，确认后执行。

![批量终止会话确认示意图，数据为虚构内容](https://cdnv2-cache.udelivrs.com/2026/10/b6fe3674b3d251056f9414b85048b1fb_1792636384653.png)

> **注意：** 终止会话会断开对应客户端连接，可能影响正在进行的业务请求。请确认目标会话后再执行。

## 分布式版 Redis

分布式版 Redis 的会话管理页面区分**分片**和**代理**，可分别查看和管理：

- **分片：** 可查看分片实例会话，并终止指定会话。
- **代理：** 可查看代理连接，并关闭指定连接。

![分布式 Redis 分片和代理会话视图示意图，数据为虚构内容](https://cdnv2-cache.udelivrs.com/2026/10/1718553e91a26d1bc5f949f7da6435c2_1792636496120.png)

执行终止或关闭操作前，请核对当前选择的分片、代理及目标会话或连接，避免影响其他客户端。
